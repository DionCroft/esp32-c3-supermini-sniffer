# Third-Party Notices

## Fonts (SIL Open Font License 1.1)

The dashboard (`data/index.html`) embeds two pixel fonts as base64 `data:` URIs
so the device serves them fully offline — no CDN, no external requests.

| Font | Usage | Canonical source |
|---|---|---|
| **Press Start 2P** | Headings, buttons, HUD | https://fonts.google.com/specimen/Press+Start+2P |
| **VT323** | Body text, tables, canvas labels | https://fonts.google.com/specimen/VT323 |
